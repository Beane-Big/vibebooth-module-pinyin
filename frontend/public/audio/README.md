# 拼音录音

这里的录音来自开源项目 [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn)（提交 `f759a0f`），许可证是 [CC BY-SA](https://creativecommons.org/licenses/by-sa/3.0/)。

- 音节录音：Chen Wang 录制（audio-cmn 的 `24k-abr/syllabs/`），原文件名 `cmn-ba1.mp3` 去掉 `cmn-` 前缀后放在这里，内容没有改动。
- `ju4.mp3`：音节录音里缺 ju4，用 Yue Tan 录制的“句”（`24k-abr/hsk/cmn-句.mp3`）代替。
- `zhengti-rendu.mp3`：把 Yue Tan 录制的“整体”“认”“读”三段（`24k-abr/hsk/`）去掉首尾静音后拼在一起，再统一了音量。这个文件同样按 CC BY-SA 发布。

只放了拼音练习用得到的音节（四个声调），文件名是“音节 + 声调数字”，ü 写成 v。录音里几乎没有轻声，所以界面上不提供轻声。
